# Roadmap

## v0.2 - Publishable Maintainer MVP

- Default path redaction for shareable reports
- Weekly Markdown maintainer report export
- GitHub issue templates for bugs, feature requests, and integration requests
- Repository screenshots and demo report

## v0.3 - Maintenance Outcome Signals

- Connect local sessions to Git branch names and commit metadata
- Optional GitHub issue/PR import
- Label sessions by workflow: triage, review, implementation, release, security
- Export before/after metrics for maintainer reports

## v0.4 - API Credit Workflows

- Optional OpenAI-powered aggregate summaries
- Long-session failure classification
- Project-instruction drift suggestions
- Release triage briefing from aggregate metrics

## Principles

- Raw Codex logs stay local by default.
- Published reports must be safe to share without leaking repository paths or prompts.
- The dashboard should answer maintainer workflow questions, not just display cost charts.
